# Odds · store preview

A working homepage and shop design for **Odds** (أودز), everyday cotton socks made in Egypt.

**Live:** https://band-agents.github.io/odds-website/

Built on the "Comfort" direction: white shelf, dark-red signature panel, real product photography.

What works in the preview:
- Hero slider, mega menu, search with live results
- The full range of 24 styles with filters (who, cut, pack size, colour), live counts and sorting
- Quick view with gallery, colour and quantity
- Bag and saved drawer, kept between visits on the same browser
- Build-your-own pack with real sock photos
- Height guide slider
- English and Arabic (right-to-left) switch

Prices, the free-delivery threshold, some product names and the build-your-own-pack offer are placeholders for review. Checkout is not connected.
